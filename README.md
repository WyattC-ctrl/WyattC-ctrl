## 👨‍🏫 Teaching

**Course Instructor** | Intro to Backend Development (CS 1998), Cornell AppDev

I teach Cornell students to build backend services from scratch with Python and Flask. Students start with their first API route and finish by deploying containerized apps.

- Lead weekly live-coding demos on routes and REST APIs, databases, relational databases with SQL, ORM abstractions and containerization with Docker
- Teach API testing with Postman and help students debug their servers
